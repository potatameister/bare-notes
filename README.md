# Bare Notes

A tiny, fast, offline notes app for Android.

- No accounts
- No ads
- No tracking
- No internet permission
- Notes stored locally as JSON

## Status

v0.1 — early build.

## Install

Download the APK from the latest GitHub Actions run:

1. Open the **Actions** tab.
2. Open the latest **Android** run.
3. Download the `bare-notes-debug` artifact.
4. Install `app-debug.apk` on your phone.

## Build

The APK is built in GitHub Actions with Gradle. No local Android SDK is required.
